# Skorbota Website

Вебсайт, створений для надання інформації та послуг ритуального характеру. Проєкт розроблено з акцентом на стриманий дизайн, зручну навігацію та адаптивність для різних пристроїв.

## 🚀 Технології та інструменти

* **HTML5** — семантична верстка
* **CSS3** — стилізація та адаптивний дизайн
* **JavaScript** — інтерактивні елементи

## 🛠️ Як відкрити проєкт локально

1. Завантажте архів з проєктом або клонуйте репозиторій.
2. Відкрийте файл `index.html` у своєму браузері.
